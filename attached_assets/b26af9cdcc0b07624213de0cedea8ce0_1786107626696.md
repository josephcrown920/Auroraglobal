# Rhythmic Title Syncing Guide

This guide details how to implement autonomous dynamic title triggers that align perfectly with musical beats.

## 1. Impact Detection (Perception)
The agent must first identify the 'High Energy' timestamps where a title should appear.
```python
def get_impact_beats(audio_path):
    # Analyze for peak transients (snares, kicks, bass drops)
    prompt = "Identify the timestamps of the 5 most powerful bass drops or drum hits in this track."
    peaks = tools.understand_material(file_paths=[audio_path], prompt=prompt)
    return parse_timestamps(peaks)
```

## 2. Dynamic Template Selection
The agent searches for 'Text Templates' that match the video's energy level.
```python
def select_title_style(mood):
    # Energetic mood -> Glitch, Bounce, or Pop templates
    # Calm mood -> Fade, Minimalist, or Typewriter templates
    query = f"{mood} dynamic text animation"
    templates = tools.search_capcut_material(type='text_template', prompt=query)
    return templates[0].id
```

## 3. STDraft Synchronization (Execution)
The key is to align the `target_timerange.start` of the text segment with the beat timestamp.
```json
{

  "target_timerange": {
```
