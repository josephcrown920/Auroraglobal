
PROMPT FOR GEMINI (ADVANCED VIDEO AI PIPELINE – COLAB)

Build a complete Google Colab notebook that creates an AI video generation pipeline with motion control, style transfer, and lip sync.

⸻

🎯 OBJECTIVE

Create a system that takes:

	•	Input: image (avatar/character) + audio (song/voice)
	•	Output: stylized animated video with synchronized lip movement and controlled motion

⸻

⚙️ CORE FEATURES

1. Motion Control (CRITICAL)

	•	Implement motion-guided animation using:
	•	ControlNet (OpenPose / Depth / Scribble)
	•	OR AnimateDiff / similar lightweight motion model
	•	Allow:
	•	Upload motion reference video OR pose sequence
	•	Extract pose frames
	•	Apply motion to static image

⸻

2. Style Transfer (VISUAL QUALITY)

	•	Apply consistent style across frames:
	•	Stable Diffusion + ControlNet
	•	Option for LoRA / custom style weights
	•	Maintain:
	•	Face consistency (very important)
	•	Outfit consistency
	•	Add toggle:
	•	“High quality (slower)”
	•	“Fast mode (lower VRAM)”

⸻

3. Lip Sync (AUDIO → FACE)

	•	Implement lip sync using:
	•	Wav2Lip OR SadTalker OR equivalent
	•	Input:
	•	Audio file (music or speech)
	•	Output:
	•	Video with accurate mouth movement synced to audio

⸻

4. Pipeline Flow

	1.	Upload avatar image
	2.	Upload audio
	3.	Upload motion reference (optional)
	4.	Generate motion frames
	5.	Apply style transfer frame-by-frame
	6.	Run lip sync on final frames
	7.	Combine into final video (MP4)

⸻

5. Smart Optimization (IMPORTANT)

	•	Detect GPU availability
	•	Enable:
	•	Low VRAM mode (for free Colab)
	•	Frame batching
	•	Clear memory between stages
	•	Cache models in Google Drive

⸻

6. Auto Fallback System

If Colab GPU fails or disconnects:

	•	Save progress to Google Drive
	•	Allow resume from last completed stage
	•	Optional:
	•	Send job to external API (RunPod-style endpoint)

⸻

7. UI (INSIDE COLAB)

	•	Build Gradio interface:
	•	Upload inputs
	•	Select:
	•	Style preset
	•	Motion type
	•	Lip sync model
	•	Preview video output

⸻

8. File Handling

	•	Mount Google Drive
	•	Save:
	•	Frames
	•	Final videos
	•	Logs

⸻

🧱 STRUCTURE (VERY IMPORTANT)

Organize notebook into sections:

	1.	Setup & Install
	2.	Model Downloads
	3.	Motion Control Functions
	4.	Style Transfer Functions
	5.	Lip Sync Functions
	6.	Video Assembly (FFmpeg)
	7.	UI (Gradio)

⸻

🚀 OUTPUT REQUIREMENTS

	•	Provide full working Colab notebook (cell by cell)
	•	Include comments for each section
	•	Ensure it runs from a fresh runtime
	•	Avoid broken dependencies

⸻

⚡ EXTRA (HIGH PRIORITY)

	•	Optimize for FREE Colab usage
	•	Use lightweight models where possible
	•	Reduce crashes and memory overflow
	•	Keep install time minimal

⸻

🎬 FINAL GOAL

A complete AI video engine that:

	•	Animates a static avatar
	•	Applies cinematic style
	•	Syncs perfectly with audio
	•	Outputs ready-to-post content (music videos, reels, etc.)
