-----------------------------------
⚡ PERFORMANCE RULES (STRICT)
-----------------------------------
- Use static-first architecture where possible

- Implement lazy loading for all below-the-fold assets
- Use responsive images (srcset)
- Inline critical CSS (above-the-fold)
- Defer or async all JavaScript
- Remove unused CSS and JS
- Avoid heavy frameworks and unnecessary dependencies
- Replace carousels/sliders with static sections
- Use system fonts or max 1 custom font (self-hosted)
- Use font-display: swap
- Preload hero image and key fonts
- Enable compression (Brotli/Gzip)
- Implement aggressive caching strategy

-----------------------------------
🌍 CDN + DELIVERY
