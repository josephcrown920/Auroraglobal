197 - Spin Engine: 50-Post Viral Campaign Upgrade

What & Why

The current Spin engine generates 30 posts using a basic variation prompt that produces near-identical outputs — same lighting, same framing, same outfit across the batch. The user's master prompt defines a strict variation engine that builds a matrix (10 locations × 10 outfits × 8 lighting styles × 8 camera styles × 8 moods) and randomly combines them to guarantee maximum variation. Count increases from 30 → 50. Each post also gets a structured per-image render prompt that feeds directly into the image model with identity lock.

Done looks like

Spin generates 50 unique posts per run (SPIN_COUNT = 50)
The LLM planner uses the new VIRAL_SYSTEM_PROMPT that includes the variation matrix driver block
No two posts in a batch share the same scene, outfit, or composition
Each post spec includes: type, hook, scene, outfit, location, camera, lighting, mood, caption, motion
The per-image render prompt sent to the image model uses the interpolated template: Same person as reference image. Scene: {scene}. Location: {location}. Outfit: {outfit}. Lighting: {lighting}. Camera: {camera}. Mood: {mood}. Ultra-realistic, cinematic, high detail, social media style, TikTok aesthetic, 9:16 vertical. DO NOT change face identity.
Credit cost updated to 50 Aura upfront (1 per post)
UI copy on /spin and landing section updated from "30 scroll-stopping pieces" → "50 scroll-stopping pieces"
The deterministic fallback buildFallbackSpecs() is extended to cover 50 posts with coprime axis lengths ≥ 50
Out of scope

Changing the rendering backend (still uses existing orchestrator + google/nano-banana or equivalent)
Adding video generation to Spin posts (images only in this pass)
Chaining Spin output into Colors Studio automatically (that is the optional next-level step)
Steps

Update SPIN_COUNT and credit reservation — Change SPIN_COUNT from 30 to 50 in src/lib/spin-engine.ts. Update the upfront credit reservation in src/lib/spin.functions.ts to reserve 50 Aura.
Replace VIRAL_SYSTEM_PROMPT — Swap in the new master prompt in src/lib/spin-engine.ts. The prompt must include: (a) the variation matrix driver block that silently builds 10 unique locations, 10 outfits, 8 lighting styles, 8 camera styles, 8 moods before generation; (b) the strict no-repetition rule; (c) the content-type mix (talking head, lip-sync, carousel, story, meme, BTS, POV); (d) the viral structure per post (hook, scene, outfit, location, camera, lighting, mood, caption, motion); (e) the JSON array output schema matching SpinPlanSchema.
Update per-post render prompt template — In the tickSpinJob function in src/lib/spin.functions.ts, replace the current prompt construction with the interpolated identity-locked template: "Same person as reference image. Scene: {scene}. Location: {location}. Outfit: {outfit}. Lighting: {lighting}. Camera: {camera}. Mood: {mood}. Ultra-realistic, cinematic, high detail, social media style, TikTok aesthetic, 9:16 vertical. DO NOT change face identity." Each field is drawn from the post spec returned by the LLM planner.
Extend fallback spec generator — Update buildFallbackSpecs() to produce 50 specs. Ensure the coprime axis arrays (locations, outfits, etc.) have lengths whose LCM ≥ 50 so the modulo rotation never repeats within a batch.
Update UI copy — In src/routes/spin.tsx and any landing page section referencing "30 scroll-stopping pieces" or "Spin 1→12/30", update the count to 50 and the subtitle to match the new "50 UNIQUE posts with EXTREME variation" framing.
