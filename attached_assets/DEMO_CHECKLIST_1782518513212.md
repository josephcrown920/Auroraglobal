## Talking Points

### On Kling Direct API

“We ditched the intermediary Replicate gateway and integrated directly with Kling’s API. This gives us three benefits: (1) lower latency, (2) full control over parameters like camera_control, and (3) proper JWT authentication. Every request is signed with your Kling secret key.”

### On Motion Control

“Before, the camera movement UI element existed, but it just appended text to the prompt. Kling never actually received the camera_control parameter, so motion did nothing. Now it’s a real API field. You can see in the console exactly what we’re sending — `camera_control: zoom_in` or `orbit_cw` — and the video output reflects that cinematic motion.”

### On End-Frame Interpolation

“Kling supports start→end frame interpolation. You upload a starting pose and an ending pose, and it smoothly animates between them. This was never hooked up before because the data wasn’t flowing through. Now it is.”

### On Split Reality

“This was a simple but critical bug. The code was trying to use `google/gemini-3.1-flash-image-preview`, which doesn’t exist on the Lovable AI gateway. We corrected it to `gemini-2.5-flash-image`, which is deployed and working. Now both variants generate perfectly.”

### On Lipsync

“sync.co is the fastest lipsync provider in the market. It was configured as the primary path but the `SYNC_API_KEY` environment variable was missing, so it was dead. Now it’s configured and working. If sync.co has an outage, it automatically falls back to GPU workers.”

### On Orchestration

“The orchestrator implements priority chains for each feature type. For video, it tries Kling first, then GPU workers. For lipsync, sync.co first, then GPU workers. For images, HuggingFace first, then GPU workers. Every provider logs its requests — latency, cost, status — so you can see exactly what’s happening.”

## Backup Talking Points (If Questions Come Up)

**Q: What if I want Seedance video instead of Kling?**
A: Right now you’d use GPU workers. We prioritized Kling because of the direct API integration. Seedance can be added as another direct integration in a future update.

**Q: How much does each feature cost?**
A: HuggingFace images ~$0.003, Kling video ~$0.50, sync.co lipsync ~$0.25. All logged in the provider_logs table.

**Q: Why JWT for Kling?**
A: It’s Kling’s API requirement. We handle the signing automatically — you just provide the keys.

**Q: What if Kling is down?**
A: Falls back to GPU workers. Health tracking will mark Kling as unhealthy after 3 failures and cooldown for 5 minutes, then retry.

**Q: Can I mix providers? Like Kling for video but a different provider for lipsync?**
A: Yes, you select the model/provider in the UI. Each feature has its own model selector.

**Q: How long does a video take?**
A: Kling standard (8fps) 30-60 seconds. Master (24fps) 60-120 seconds. Console shows real-time polling so you can watch it progress.
