## Full Description (4000 chars max)

**Aurora Performance Studio** is a mobile creative workspace for artists, performers, and content creators. Generate AI images and videos from a prompt or reference photo, direct camera movement, and build performance-focused visuals from your phone.

### What You Can Create

🌟 **AI Images** — Create performance-focused images from a prompt, with an optional reference photo.

🎬 **AI Videos** — Create video from text or animate a reference photo.

🎥 **Camera Motion** — Choose motion controls such as push in, orbit, pan, handheld, or static where available.

⚡ **Perform Anywhere** — Use a photo or a short performance clip to stage performance visuals and direct the scene.

✏️ **Creative Direction** — Describe the scene, style, and movement you want.

### Features

✓ Email account access
✓ Personal gallery for completed creations
✓ Image and video generation
✓ Camera-motion controls
✓ Aura balance, generation costs, and credit history
✓ In-app account deletion
✓ Reference photo and short performance-clip support

### How It Works

1. Choose image, video, or Perform Anywhere.
2. Enter your creative direction and optionally add supported reference media.
3. Review the displayed Aura cost or starting cost.
4. Start the generation and follow its status.
5. Find completed work in your gallery.

### Credits

Aurora Performance Studio uses Aura credits for generation. The mobile app displays your available balance, generation pricing, and credit history. The mobile app does not sell Aura and contains no top-up button or payment link.

### Privacy

Review how Aurora Performance Studio handles account and generation data in the privacy policy at auroraperformancestudio.com/privacy. Store data-safety declarations must be completed and reviewed by the owner against the submitted build.

## Build & Submission Notes

### Android production build

```bash
cd artifacts/aurora-mobile
npx eas build --platform android --profile production
```

This should produce a fresh `.aab` (Android App Bundle) with `versionCode` 3. Confirm the build metadata before upload. Do not use the existing vc2 AAB for the current listing because it has OLD branding.

### iOS build

Use Replit **Publish** for the Aurora Performance Studio mobile artifact / Expo Launch. Do not use CLI submission instructions for iOS.

### For internal testing:
```bash
# Android APK
npx eas build --platform android --profile preview
```

### Before submission, ensure:
1. App icons at `assets/images/icon.png` (1024×1024)
2. Splash screen at `assets/images/splash.png` (1242×2436)
3. EAS project ID is set (run `npx eas init` if not set)
4. `buildNumber` in `app.json` `ios` section is incremented for each iOS release
5. `versionCode` in `app.json` `android` section is incremented for each Android release

### Play Store internal track submission (Android v1 — manual upload):

Create a fresh production AAB from the current `versionCode` 3 configuration,
confirm its branding and version code, then upload it by hand in **Play Console
→ Testing → Internal testing → Create release**. The existing vc2 AAB has OLD
branding and is not recommended for upload.
The manual browser upload is the only sanctioned submission path for this app;
`store/submission-guide.md` has the full walkthrough.

### App Store Connect submission:

Use Replit **Publish** for the Aurora Performance Studio mobile artifact / Expo
Launch when the iOS follow-up begins. iOS is not part of the Android v1 release.
