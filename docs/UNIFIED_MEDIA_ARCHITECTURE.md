# Unified Media Architecture

Aurora Global is the canonical application. Comfy-Manager capabilities are integrated behind Aurora's existing TanStack Start, authentication, Supabase, orchestration, and worker systems.

Core capabilities: ComfyUI workflows; ModelArk Seedream/Seedance; BytePlus Video Agent; cinematic and viral workflow registries; image-to-video; character video; lip-sync; Perform Anywhere; GPU Hub; free Colab/Kaggle workers; durable jobs; worker routing; batches; outputs.

The migration intentionally does not add a second application shell, router, authentication system, package manager, or production API server.
