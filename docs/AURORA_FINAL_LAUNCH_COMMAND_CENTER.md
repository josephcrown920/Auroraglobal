## Provider guard
Every generation containing a real-person reference must pass through the centralized identity/provider guard. Never bypass provider restrictions. If a provider requires an authorized/trusted identity asset, use the supported mechanism or choose another eligible provider.

## TikTok 30 invariant
SPIN_COUNT and SPIN_PIECE_COUNT must both equal 30. Customer-facing Spin metadata must say TikTok 30. The proof test must produce 30 requested variants.

## Finish rule
No new major product categories. Finish -> prove -> demo -> deploy -> ship.
